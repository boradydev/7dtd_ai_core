# 7dtd-ai-core: Roadmap & Architecture

Проект интеллектуального администратора сервера 7 Days to Die на базе локальной LLM и видеокарты NVIDIA CMP 90HX.

---

## 🏗️ Архитектурная концепция
- **Core**: Асинхронное приложение на `aiogram` (дирижер задач).
- **Inference**: Ollama (Llama 3 8B) на GPU CMP 90HX.
- **Storage**: PostgreSQL (История чатов, контекст, данные игроков).
- **Transport**: 
    - *Input*: Парсинг `output_log.txt` (Tail -f подход).
    - *Output*: 7dtd-api (отправка команд в консоль сервера).

---

## 📅 Этапы реализации

### Этап 1: Инфраструктура и Базис
- [ ] **Настройка окружения**:
    - Создание проекта в PyCharm (Python 3.13).
    - Настройка `docker-compose.yml` (PostgreSQL + PgAdmin).
    - Создание `.env` (Токены, параметры БД, пути к логам).
- [ ] **Транспортный уровень**:
    - Перенос и адаптация `LogFileTailer` (асинхронное чтение лога 7dtd).
    - Написание `TelnetClient` (модуль для выполнения команд `say`, `ban`, `tp`).
- [ ] **Telegram Admin**:
    - Базовый бот на `aiogram` для управления системой.

### Этап 2: Интеллект и Память
- [ ] **База данных**:
    - Схема таблиц: `players`, `chat_history`, `server_events`.
    - Реализация методов сохранения и получения N-последних сообщений.
- [ ] **AI Engine (Ollama)**:
    - Интеграция `ollama.AsyncClient`.
    - Разработка **System Prompt** (роль админа, технический стек, запрет на английский).
    - Настройка параметров генерации (`temperature`, `top_p`) для минимизации "шума".

### Этап 3: Вертикальная фича "Живой Админ"
- [ ] **Event Pipeline**:
    - Реализация `asyncio.Queue` для передачи событий из лога в AI.
    - Обработчик: Лог -> Очередь -> AI -> Telnet (ответ в игру).
- [ ] **Реакция на события**:
    - Авто-приветствие новых игроков.
    - Ответы на вопросы в игровом чате в реальном времени.

### Этап 4: Function Calling и Аналитика (PRO)
- [ ] **Управление намерениями (Intents)**:
    - Обучение модели распознавать команды (например: "админ, забань читера").
    - Безопасная прослойка проверки прав перед выполнением команд.
- [ ] **Feedback Collector**:
    - Фоновая задача на саммаризацию логов за час/день.
    - Сбор жалоб и предложений игроков в отдельную таблицу.
- [ ] **Мониторинг железа**:
    - Вывод статуса CMP 90HX (VRAM, Temp) прямо в Telegram.

---

## 🛠️ Технологический стек
- **Language**: Python 3.13 (Asyncio)
- **AI**: Ollama + Llama 3 8B (Quantization Q4_0)
- **DB**: PostgreSQL (JSONB для контекста)
- **Bot**: aiogram 3.x
- **Hardware**: NVIDIA CMP 90HX (10GB GDDR6X)

---

## ⚓ Важные заметки (Не забыть!)
- **Context Pruning**: Очищать старые сообщения из контекста, чтобы не выйти за лимит 8192 токена.
- **SteamID**: Всегда привязывать историю к SteamID, а не к нику (ники можно менять).
- **Security**: Жестко ограничить список Telegram ID, имеющих доступ к управлению сервером.
- **GameEvents**: Логи читаем напрямую из контейнера через socket.
