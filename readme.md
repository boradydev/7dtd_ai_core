# AI core for 7 Days to Die

Мост между игровым сервером 7 Days to Die и искусственным интеллектом.

Проект позволяет анализировать события игрового сервера, взаимодействовать с игроками через игровой чат и автоматически выполнять действия в игре с помощью ИИ.

## ✨ Возможности

* Сбор отзывов и предложений игроков через игровой чат.
* Выдача предупреждений и банов на основе решений ИИ.
* Генерация ответов игрокам в игровом чате.
* Вызов игровых событий через GameAPI.
* Проверка и нормализация текста с помощью LanguageTool.
* Поддержка локальных LLM через Ollama.

## 🏗 Архитектура

Проект построен на основе Event Driven Architecture.

1. Приложение отслеживает лог-файл сервера 7 Days to Die.
2. Новые записи преобразуются в события.
3. События распределяются по маршрутам.
4. Маршруты вызывают соответствующие Use Cases.
5. Use Cases взаимодействуют с ИИ, базой данных и игровым API.
6. Результатом работы могут быть сообщения в чат, игровые команды, предупреждения, баны и другие действия.

```text
Log File
    ↓
 Event
    ↓
 Route
    ↓
 Use Case
    ↓
 ├─ Ollama
 ├─ LanguageTool
 ├─ PostgreSQL
 └─ GameAPI
```

## 📦 Основные компоненты

* **Ollama** — локальные языковые модели.
* **GameAPI** — взаимодействие с сервером игры.
* **PostgreSQL** — хранение данных и истории событий.
